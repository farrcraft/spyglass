# Implementation plans

Plans turn a [roadmap milestone](../roadmap/README.md) into concrete work. Start from [template.md](template.md) and name the file after its milestone: `mNN-slug.md`. When a plan is done, move it to [completed/](completed/). See [development-process.md](../development-process.md) for the full lifecycle.

Code must not reference plans. Anything durable a plan produces belongs in a spec or ADR.

## Active

- [m22-user-guide](m22-user-guide.md): the user guide on GitHub Pages, for milestone [22](../roadmap/22-user-guide.md).
- [m29-flower-fields](m29-flower-fields.md): the flower bone meal grows at any block and height, on the map, at the best height for an area, and as a search, for milestone [29](../roadmap/29-flower-fields.md).

The follow-ups of milestones 08 and 11 ([roadmap](../roadmap/README.md#follow-ups)) need no plan of their own.
