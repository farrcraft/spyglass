# Implementation plans

Plans turn a [roadmap milestone](../roadmap/README.md) into concrete work. Start from [template.md](template.md) and name the file after its milestone: `mNN-slug.md`. When a plan is done, move it to [completed/](completed/). See [development-process.md](../development-process.md) for the full lifecycle.

Code must not reference plans. Anything durable a plan produces belongs in a spec or ADR.
